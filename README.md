# SIHPS - Smart India Hackathon Problem Statements

A community-maintained collection of **Smart India Hackathon (SIH)** Problem Statements, organized year-wise into clean Excel and PDF files to help students easily browse, filter, and shortlist problems.

## 📂 Folder Structure & Columns
Each yearly folder contains Excel and PDF versions (standard and detailed) for both hardware and software problem statements. Columns include `Organization`, `Problem Statement`, `Background`, `Description`, `Expected Solution`, `Category`, `Ps Number`, and `Theme` (sorted alphabetically by theme).

> **Note:** This is an unofficial copy compiled from official sources. Always verify with the official SIH portal.
