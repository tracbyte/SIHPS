# Contributing to SIHPS

Contributions are welcome to keep this dataset accurate and up-to-date for future participants.

## 📌 Ground Rules
1. **Keep Headers Identical:** Do not modify or rearrange column headers (`Organization`, `Problem Statement`, `Background`, `Description`, `Expected Solution`, `Category`, `Ps Number`, `Theme`).
2. **Sorting:** Sort rows alphabetically by the `Theme` column.
3. **Missing Data:** Leave cells blank if data is missing on the official portal; do not guess or use placeholders.

## 🛠️ Workflow
1. Fork the repository and create a feature branch (`git checkout -b feature/update-data`).
2. Add or update files in the appropriate `SIHPSyyyy` folder.
3. Commit your changes (`git commit -m "Add verified statements"`) and push to your fork.
4. Open a Pull Request against the `main` branch.
